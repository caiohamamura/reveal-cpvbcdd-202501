O que é inteligência?

  • Capacidade de resolver situações novas com rapidez e êxito

O que é inteligência artificial?

Perguntando para a própria IA 🤖

IA Fraca × IA Forte

Etapa 3: Histórico da IA

Tudo começa com Alan Turing

Alan Turing — década de 1940-50

  • Considerado o pai da computação moderna
  • Desenvolveu um computador para decifrar código criptografado na Segunda Guerra Mundial
  • Encurtou a guerra em 2 a 4 anos, salvando mais de 14 milhões de vidas
  • Um dos primeiros cientistas a cogitar a possibilidade de computadores inteligentes

🎬 O Jogo da Imitação (2014)

Alan Turing

O computador do futuro seria capaz de aprender com a experiência. O caminho para isso era que ele fosse capaz de alterar as próprias instruções fornecidas por seu mecanismo.
— Alan Turing

1946 O neurônio artificial

Warren McCulloch (neurofisiologista) e Walter Pitts (matemático lógico) teorizaram:

O neurônio nada mais é que uma unidade de processamento que:

  • Recebe entradas pelos dendritos
  • Realiza alguma função internamente com os resultados
  • Emite saídas pelos seus axônios

1956 Surgimento da IA: Dartmouth

  • John McCarthy cria o termo Inteligência Artificial na Conferência de Dartmouth
  • Grupo de matemáticos, cientistas da computação e psicólogos
  • Durou 8 semanas
  • Nos anos seguintes, esses cientistas desenvolvem conceitos usados nas IAs mais modernas, como os neurônios artificiais

1958 Frank Rosenblatt: Mark I Perceptron

📺 YouTube: The Machine that Changed the World — The Thinking Machine

Por que o Mark I Perceptron morreu? 💀

  • Tinha apenas uma camada de neurônios
  • Era gigante e demorava muito tempo para treinar
  • O maior golpe foi o livro de Marvin Minsky e Seymour Papert, que demonstrou que a máquina não era capaz de realizar operações matemáticas simples como o XOR
  • Mas no capítulo seguinte eles dão a solução: criar mais uma camada de neurônios — assim ele seria capaz de generalizar qualquer função
  • A maioria não leu até esse capítulo e simplesmente deixou de lado…
  • Não havia aplicação prática? Mas sim: a das IAs simbólicas…

O inverno da IA ❄️ (até 2010)

  • Houve um esfriamento e descrédito em simular o nosso cérebro com neurônios artificiais
  • Ainda precisaríamos de máquinas muito melhores e maior capacidade de obter e armazenar dados
  • Os investimentos mudam para a IA simbólica
  • IA simbólica usa uma base de conhecimentos e faz buscas nela para encontrar respostas por uma série de regras lógicas de IF-ELSE, AND, OR etc.
  • Apesar de a IA simbólica ter algum sucesso, nunca chegou nem perto de fazer algo semelhante ao que somos capazes de fazer

Quem usa IA simbólica?

Assistente Google, Siri, Cortana, …

Sistemas especialistas: codificam os conhecimentos de especialistas com base em como eles tomam decisões

  • Paciente chega com febre, tosse, coriza → gripe
  • Paciente com dor de estômago, consome muita fritura, industrializados, cafeína e faz poucas refeições → gastrite
  • etc…

Retomando as redes neurais

  • No final da década de 1980, o interesse nas redes neurais retorna com o surgimento de algoritmos mais eficientes
  • A partir de 1990, com o crescimento da internet e do fluxo de dados, cresce o interesse em extrair informações dos dados
  • Na década de 2000, as aplicações de machine learning ganham cada vez mais força
  • Machine learning: o dispositivo aprende, com base em experiências passadas, a tomar decisões no futuro
  • Surgem diversas soluções para analisar dados mais complexos: SVM, AdaBoost, Random Forest e XGBoost

2010+ Redes cada vez mais profundas

  • Até os anos 2000, os computadores dos cientistas eram muito limitados
  • Isso muda, e redes neurais cada vez mais complexas passam a ser testadas
  • Análise de imagens com redes neurais vira o padrão ouro da visão computacional
  • Redes convolucionais: Kunihiko Fukushima (1979), usadas com sucesso por Yann LeCun (1989) para ler CEP escrito à mão

Etapa 4: Manipulação de dados com pandas 🐼

Modelos de IA aprendem com dados — antes de treinar, precisamos limpar e preparar esses dados com a biblioteca pandas.

Limpando dados

  • .isnull(): verifica se os dados são NaN (not a number / erro)
  • .fillna(): substitui dados faltantes
  • .drop_duplicates(): remove linhas duplicadas
# Substituindo dados faltantes pela média dados['idade'].fillna(dados['idade'].mean(), inplace=True) # Removendo linhas duplicadas dados = dados.drop_duplicates() # Corrigindo inconsistências dados['genero'] = dados['genero'].replace(['Feminino', 'fem'], 'F')

Manipulando dados

# Selecionando colunas dados[['age', 'sex']] # Quero ver apenas idosos dados[dados['age'] >= 60] # Agrupando dados dados.groupby('sex')['age'].mean() # Ordenando dados dados.sort_values('age', ascending=True) # Criando novas colunas dados['idoso'] = dados['age'] > 60

Etapa 5: Teachable Machine

CNN para leigos: treine um modelo de visão computacional sem escrever uma linha de código!

Iniciando o projeto

  • Acesse https://teachablemachine.withgoogle.com/train
  • Inicie um projeto de imagem

Inicie um modelo standard

Standard ✅

  • Maioria dos usos
  • Imagens maiores: 224 × 224
  • Imagens coloridas RGB

Embedded

  • Para sistemas embarcados (Arduino…)
  • Imagens menores: 96 × 96
  • Imagens em tons de cinza

A atividade 🎯

Projeto para classificar diferentes imagens. Exemplo: mostrar diferentes objetos (ou tipos de objetos) e fazer o modelo identificar o que é.

Passos:

  • Crie uma classe para cada objeto/tipo de objeto
  • Adicione fotos de exemplo para cada um
  • Treine o modelo
  • Ao final do treinamento, seu modelo conseguirá classificar ao vivo que tipo de objeto está vendo

    Renomeie e adicione classes

    • Renomeie as classes com o nome de cada objeto (clique no lápis ✏️)
    • Adicione novas classes com o botão "+ Add a class"
