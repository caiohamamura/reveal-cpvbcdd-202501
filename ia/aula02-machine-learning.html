    A partir dos anos 1990, com o crescimento da internet e do fluxo de dados, cresce o interesse em extrair informação dos dados: surge o Aprendizado de Máquina.

    Aprendizado de Máquina (AM)

    • Subárea da inteligência artificial
    • Aprender com os dados anteriores para fazer predições ou decisões, sem precisar criar um programa específico para isso
    • Nas décadas de 1990 e 2000, os dados na maioria eram em formato de tabela

    Usos do Aprendizado de Máquina

    Detecção de fraude

    Classificar transações de cartão como legítimas ou suspeitas

    Detecção de SPAM

    Classificar e-mails como spam ou legítimos automaticamente

    Quando uso Aprendizado de Máquina?

    Existem dois tipos principais:

    Classificação

    Prever uma classe.

    Ex.: a partir dos dados do paciente, prever o risco de ataque cardíaco (classe: alto ou baixo)

    Regressão

    Prever um número.

    Ex.: a partir de dados de imóveis, prever o preço de mercado (um número: o preço)

    🤔 Definição do problema

    • Qual problema queremos resolver?
    • Qual a melhor maneira de resolver isso?
    • Existe alguma forma já bem estabelecida de resolver?
    • Qual a natureza das informações que podemos obter?
    • Como e onde podemos obter os dados?
    • Precisamos medir? Fazer experimentos?

    Bases já disponíveis

    • Kaggle
    • Hugging Face

    Coletar você mesmo

    • Experimento: delineamento experimental

    ⛏️ Coleta de dados: amostrar a diversidade

    Ao planejar ou delinear um experimento, é preciso amostrar o máximo de condições possíveis:

    • Tamanhos: pequeno, médio, grande
    • Pessoas: várias faixas etárias, hábitos, culturas, crenças, etnias
    • Imagens: fotos de dia e de noite, ensolarado, diferentes iluminações…

    📊 Tratamento de dados

    Analisar e corrigir problemas

    • Dados faltantes
    • Dados fora do padrão (erro de digitação? número fora da realidade?)
    • O que fazer? Imputar valores (média)? Remover a linha? Descartar só o dado?

    Transformar os dados

    • Alguns modelos exigem que os dados sigam um padrão
    • Podemos transformar os dados para que sigam esse padrão

    🔎 Seleção de variáveis

    • Algumas variáveis claramente não ajudam a predizer (ex.: número da linha)
    • Variáveis correlacionadas mostram a mesma coisa — basta uma: temperatura corporal e febre (melhor usar a temperatura, mais exata)
    • Variáveis válidas, mas sem relação com o objetivo: prever o preço de venda de uma casa a partir do número da casa — provavelmente sem relação alguma

    ➗ Divisão dos dados

    Treinamento
    70–80%
    Validação
    10–15%
    Teste
    10–15%
    • Treinamento: dados usados para treinar o modelo
    • Validação: dados usados para saber quando parar de treinar
    • Teste: dados usados para verificar a qualidade do modelo final

    Um dado só aparece em um dos três — nunca se repete — para garantir que o modelo saiba lidar com amostras nunca vistas antes.

    🤖 Escolha do modelo

    Dependendo do objetivo, selecionamos modelos diferentes:

    • Quer entender o problema e do que ele depende? Modelos estatísticos, floresta aleatória e XGBoost mostram com clareza as variáveis mais importantes
    • Melhores resultados em dados tabulares: floresta aleatória e XGBoost
    • 🖼️🎥🔊 Melhores resultados em dados complexos: aprendizado profundo (redes neurais artificiais)

    🤖 Treinamento do modelo

    Treinar é mostrar ao modelo os dados de exemplo. Cada modelo aprende de um jeito, mas todos estão sujeitos a efeitos que atrapalham o resultado:

    • Amostragem ruim: não amostrar a diversidade; o modelo aprende "errado"
    • Subajuste: não treinar ou não aprender o suficiente sobre os dados
    • Sobreajuste: treinar demais; o modelo fica "viciado" e só acerta nos dados em que foi treinado

    🎯 Validação

    • A validação serve justamente para sabermos quando parar de treinar
    • A cada treino, verificamos a qualidade do resultado contra o conjunto de validação
    • Quando a validação começa a piorar, é hora de parar de treinar

    👩🏻‍🔬 Teste

    O teste é o resultado final. A avaliação depende do tipo de predição:

    Classificação

    Acurácia geral, kappa, F1-score, sensibilidade/especificidade, acurácia do produtor e do usuário, erros de inclusão e omissão…

    Regressão

    Erro médio quadrático (RMSE), erro absoluto médio (MAE), R²

    Etapa 3: Regressão Logística

    Um modelo estatístico muito usado dentro do aprendizado de máquina para problemas de classificação.

    Para que serve a regressão logística?

    • Aceita múltiplas variáveis e sua saída é um valor entre [0, 1] — interpretável como sim (1) ou não (0)
    • Usada para classificar entre SIM/NÃO ou descobrir a probabilidade de algo:
      • Um e-mail ser spam ou não
      • Um paciente ter ou não uma doença
    • É calculada rapidamente e vem sendo amplamente usada desde meados de 1970

    A função sigmóide

    A regressão logística usa a função sigmóide, que "espreme" qualquer número real para o intervalo [0, 1]:

    $$g(z) = \frac{1}{1 + e^{-z}}$$

    Somando as variáveis com pesos

    • Em vez de $x$ ser uma única variável, somamos todas as variáveis dando um peso ($w$, de weight) para cada uma:
    $$z = vi\acute{e}s + w_1 x_1 + w_2 x_2 + \dots + w_n x_n$$
    • O que a regressão precisa aprender é como escolher os pesos $w_1, w_2, w_3 \dots$ para chegar mais próximo do resultado real (de 0 a 1)

    Etapa 4: Como a regressão aprende?

    Usamos um algoritmo chamado gradiente descendente (gradient descent).

    Gradiente descendente

    Imaginamos a perda (loss) — o quão ruim o modelo está — em função do peso. Queremos chegar ao ponto de perda mínima.

    Para isso precisamos definir duas coisas:

    • A função de perda (loss)
    • O gradiente: quanto ela está mudando?

    A função Loss (perda)

    Exemplo: prever a chance de ataque cardíaco. Primeiro, tratamos os dados (sim → 1, não → 0):

    IdadeSexoPressãoColest.Batim.Açúcar Hist. Fam.Ataque
    45M1302008010011
    55F1452407015001
    60M120180909010
    50M1352207516011
    40F125190859500

    O quão certo está o modelo?

    Supondo que o modelo tenha previsões $\hat{y}$, podemos medir o acerto por linha:

    • Se o resultado verdadeiro $y$ for 1 → acerto $= \hat{y}$
    • Se o resultado verdadeiro $y$ for 0 → acerto $= 1 - \hat{y}$

    Podemos escrever as duas regras em uma só fórmula:

    $$\hat{y}^{\,y} \cdot (1 - \hat{y})^{\,1 - y}$$

    Juntando todas as probabilidades

    • Multiplicando o acerto de todas as linhas, obtemos o quão correto está o modelo inteiro
    • Em matematiquês isso é um produtório. A fórmula é a verossimilhança ($L$, de likelihood — o quão provável):
    $$L = \prod_{i=1}^{n} \hat{y}_i^{\,y_i} \cdot (1 - \hat{y}_i)^{\,1 - y_i}$$

    Da verossimilhança à função Loss

    • Para evitar trabalhar com produtório, aplicamos a função log, que transforma o produto em somatório:
    $$\log L = \sum_{i=1}^{n} \big( y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \big)$$
    • Como o resultado costuma ser negativo, invertemos o sinal e obtemos a nossa função de Loss:
    $$Loss = -\sum_{i=1}^{n} \big( y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \big)$$

    E o gradiente?

    A linha de tendência da curva é a derivada — neste caso, da função Loss em relação ao peso.

    Se eu descobrir a derivada, sei para que lado preciso ir e o quanto!

    $$\frac{\partial Loss}{\partial w_i}$$

    Derivando pela regra da cadeia

    Só conseguimos derivar em relação a $z$ e $\hat{y}$ (só elas aparecem na Loss). Usamos a regra da cadeia para chegar até o peso $w_i$:

    $$\frac{\partial Loss}{\partial w_i} = \frac{\partial Loss}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial w_i}$$

    Cada pedaço tem uma derivada conhecida:

    • $\dfrac{\partial Loss}{\partial \hat{y}} = \dfrac{\hat{y} - y}{\hat{y}(1 - \hat{y})}$
    • $\dfrac{\partial \hat{y}}{\partial z} = \hat{y}(1 - \hat{y})$   (derivada da sigmóide)
    • $\dfrac{\partial z}{\partial w_i} = x_i$

    Substituindo os três

    Ao multiplicar as três partes, os termos $\hat{y}(1 - \hat{y})$ se cancelam e sobra algo surpreendentemente simples:

    $$\frac{\partial Loss}{\partial w_i} = (\hat{y} - y)\, x_i$$

    Isso é ótimo, porque já temos tudo: o erro $(\hat{y} - y)$ e as variáveis $x_i$!

    Atualizando o peso pelo gradiente descendente

    $$w_j = w_{j_{velho}} - \alpha \, \frac{\sum x_i (\hat{y}_i - y_i)}{n}$$
    $w_{j_{velho}}$peso inicial (aleatório)
    $\alpha$taxa de aprendizado (normalmente < 1)
    $x_i$variável de cada linha
    $\hat{y}_i - y_i$erro (resíduo)
    $n$número de linhas

    Etapa 5: Exemplo prático completo

    Percorrendo o pipeline inteiro para prever o risco de ataque cardíaco:

    • 🤔 Definição — prever risco de ataque cardíaco
    • ⛏️ Coleta — da internet (Heart Disease Dataset)
    • 📊 Tratamento — o que a regressão logística vai precisar
    • 🔎 Seleção — podemos pular, a máquina aprende os pesos
    • 🤖 Modelo — regressão logística
    • 🎯 Validação — verificar a hora de parar o treino

    ⛏️ Coleta de dados

    Vamos baixar o conjunto da internet:

    Heart Disease Dataset (Kaggle)

    kaggle.com/datasets/johnsmith88/heart-disease-dataset

    📊 Tratamento de dados

    Para a regressão logística, vamos precisar:

    • Transformar variáveis categóricas (textos ou números que são categorias, não quantidades) em números
    • Para o gradiente descendente, deixar todas as variáveis numéricas na mesma escala, idealmente de 0 a 1
    • Caso contrário, o erro fica muito diferente entre as colunas e atrapalha o ajuste dos pesos

    📊 Transformar categóricas (binárias)

    Se a categoria tem dois valores (sim/não, M/F), usamos 0 e 1:

    SexoHist. Fam.
    MSim
    FNão
    MSim
    →
    SexoHist. Fam.
    01
    10
    01

    0 representa uma categoria e 1 representa a outra.

    📊 One-Hot-Encoding

    Quando há mais de duas categorias, criamos uma coluna para cada uma:

    Podemos tirar a primeira coluna: se as outras forem 0, já se sabe que só pode ser ela.

    📊 Padronizar variáveis numéricas

    Para a regressão logística, usamos o mínimo e o máximo para levar cada coluna ao intervalo 0–1:

    $$x_{padr} = \frac{x - x_{min}}{x_{max} - x_{min}}$$

    Exemplo (coluna Idade, valores entre 40 e 60):

    $$x_{padr} = \frac{45 - 40}{60 - 40} = \frac{5}{20} = 0{,}25$$

    📊 Adicionar a coluna de viés

    Adicionamos uma coluna viés preenchida com 1.

    Se todas as variáveis tiverem relação inversamente proporcional, o viés permite estabelecer uma linha de base positiva para o modelo ainda dar certo.

    IdadeSexo…Hist. Fam.Viés
    0,250…11
    0,751…01
    0,001…11

    🤖 Treinamento: pesos aleatórios

    Começamos escolhendo pesos aleatórios, um para cada coluna (incluindo o viés):

    IdadeSexoPressãoColest.Batim.Açúcar Hist. Fam.Viés
    0,70,90,30,6 0,11,00,20,2

    🤖 Soma ponderada, sigmóide e erro

    1. Calcular a soma ponderada $z = vi\acute{e}s + \sum w_i x_i$ de cada linha
    2. Aplicar a sigmóide para obter o estimado $\hat{y}$
    3. Calcular o erro $= \hat{y} - y$
    $y$ (Ataque)Estimado $\hat{y}$Erro
    10,7480-0,2520
    10,9671-0,0329

    🤖 Atualizando a coluna Idade

    • Multiplica idades × erros e tira a média (soma ÷ n): média do erro $\approx 0{,}1275$
    • Com taxa de aprendizado $\alpha = 0{,}3$ e peso inicial da idade $= 0{,}7$:
    $$w_1 = 0{,}7 - 0{,}3 \cdot 0{,}1275 = 0{,}7 + 0{,}03825 = 0{,}73825$$

    Repetimos isso para todos os pesos, várias vezes, até a Loss parar de melhorar.

    🎯 Verificar a hora de parar o treino

    • Ao trocar os pesos, um novo erro é gerado
    • Se o erro não melhorar, paramos de treinar
    • Mas o erro não pode ser analisado contra o próprio treinamento — e sim contra o conjunto de validação!

    👩🏻‍🔬 Resultado final

    Pelos valores dos pesos, sabemos quais colunas têm maior importância:

    • Batimentos cardíacos (-1,80)
    • Nível de açúcar no sangue (1,51)
    • Colesterol (1,11)
